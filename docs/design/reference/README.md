# Visual reference index

The approved reference screenshots previously named by the UI/UX specification
are not currently available in this repository. Their provenance and approval
cannot be reconstructed from the files available here. Do not treat a new capture
as an approved reference without product-owner approval.

Until those files are restored, use the written [UI/UX specification](../UI_UX_SPEC.md)
and existing shared components as the available design guidance, following the
priority order in `AGENTS.md`. The existing [desktop inbox](../../../assets/screenshots/inbox-desktop.png)
and [mobile reader](../../../assets/screenshots/reader-mobile.png) are demo-data
product screenshots, useful for orientation only; they are not an approved or
complete reference set.

For substantial UI changes, still inspect the actual rendered interface at the
viewports in `AGENTS.md`. Record the commit, platform, theme, viewport, text
scaling, scenarios and results with the change. If an approved reference is
needed for a decision, restore it from its authoritative source rather than
inventing one.
