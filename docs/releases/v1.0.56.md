# Better Email v1.0.56

发布日期：2026-09-07

## 登录与凭据

- 修复“账号已经登录，但统一邮箱同步仍提示本机未保存授权码”的凭据生命周期缺口：新账号、默认文件夹、身份和加密凭据在同一 SQLite 事务内创建，并在提交前读回、解密和校验。
- 登录验证改为读取已经持久化的凭据，不再使用输入框中的临时授权码绕过本机存储路径。
- 凭据健康检查明确区分缺失、密钥缺失、不可解密、认证格式错误和本机可读；不再用“数据库字段非空”代表登录正常。
- 已有密文但原密钥缺失或损坏时，不生成替代密钥覆盖故障；保留账号、缓存邮件和原始数据，提供非破坏性的“修复登录”入口。
- 修复切换账号、重复保存以及迟到异步请求可能污染另一个账号登录状态或清空较新输入的问题。
- OAuth 授权与刷新绑定目标账号，刷新结果使用旧凭据快照条件写回，避免覆盖重新登录后的新凭据或复活已删除凭据。
- 统一邮箱同步在批次限额之前检查本机凭据；异常账号不再挤掉正常账号，部分失败也不会错误显示“已是最新”。

## 界面与交互

- 修复首次启动时顶部搜索辅助说明错误显示为第二行、挤压搜索输入框的问题。
- 修复窄列表、字体放大和部分窗口尺寸下筛选/排序控件被裁切或显示不完整的问题。
- 增加首次启动、窄列表、长中英文、浅色/深色和多档字体缩放的真实 Chromium 几何与命中回归。

## Rust 与可靠性

- 修复后台任务跨 SQLite 连接并发入队可能重复创建活跃任务的问题。
- 修复失败任务重试、取消与迟到进度更新可能覆盖新状态的问题。
- 修复已发送副本留档回调的迟到结果可能降级已确认发送状态或覆盖远端 UID 的问题。
- 修复发送演练中 RFC3339 时间按字符串比较，以及消息移动与队列状态不同步的问题。
- 增加后台任务并发、重试、取消、索引查询计划、留档状态、演练事务回滚、凭据持久化、重启读取、密钥保护和 OAuth 竞态回归。

## 已知边界

真正已经丢失的授权码无法从账号元数据还原，需要在应用内重新输入；缺失的加密密钥也需要原密钥备份恢复。CI 的浏览器流程使用 mock 邮箱服务，真实 QQ/IMAP/SMTP/OAuth 服务商以及 Android/macOS/Windows 真机环境仍需要运行时验收。
