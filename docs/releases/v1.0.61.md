## Better Email v1.0.61

本次更新带来桌面端三栏布局细节精修、品牌图标细节优化与原生平台体验升级。

### 更新内容

- **桌面端三栏布局优化**：
  - 侧边栏、邮件列表与阅读区域支持自由拖拽调节宽度，并能持久记住你的偏好宽度。
  - 侧边栏支持一键折叠与展开，优化小尺寸窗口（1440/1280/1024px）下的自适应浏览体验。
  - 顶部工具栏精准适配 macOS 原生红黄绿窗口控制按钮，居中搜索栏支持 ⌘K / Ctrl+K 快捷呼出。
- **移动端多选与阅读安全升级**：
  - 移动端进入多选模式时展示清晰复选框，退出后平滑恢复头像，消除列表跳动。
  - 优化移动端列表点击区域，勾选邮件不再误触发打开。
  - 邮件阅读器安全提示条排版精简，支持折叠查看详细说明。
- **品牌图标与视觉精修**：
  - 重新绘制信封与信息流品牌图标，边缘更加平滑，遵循克制纯色视觉规范。
  - 针对 16/20/24/32px 等托盘与任务栏小尺寸进行像素级微调，高分辨率与标准屏幕下均清晰锐利。
- **Windows 系统托盘深浅色自适应**：
  - 实时响应 Windows 任务栏深浅色主题变化，浅色任务栏自动使用高对比深色图标，深色任务栏使用纯白图标。
  - 优化托盘状态切换稳定性，保留未读计数与右键托盘菜单。
- **构建资源与打包流程改进**：
  - 规范跨平台资源打包与生成流程，保证各平台安装包构建确定性与稳定性。
