## Better Email v1.0.60

本次更新改进邮件发送过程的可见性，并修复设置弹窗的排版与交互问题。

### 更新内容

- 发件时显示 SMTP 邮件数据上传进度；上传完成后继续显示等待服务器确认，区分发送失败、结果待确认和服务器已接受。
- 延迟发送与后台发送显示一致的进度；发送进行中禁止取消任务，避免界面误报或重复发送。
- 修复定时发件箱任务的调用路径，并在邮件列表刷新失败时保留真实发送结果。
- 统一附件缓存清理和模板删除的确认弹窗，修复统计文字粘连、按钮样式错误和长文本溢出。
- 改进确认弹窗的键盘焦点、Escape 取消、处理中保护和失败重试行为。
- MCP 更新：支持 Streamable HTTP 协议握手、会话关闭和邮件内容授权边界；详见 v1.0.59 更新说明。
