## Better Email v1.0.61

本次更新带来桌面端 UI/UX 全面精修、品牌视觉符号几何重构与原生平台体验升级。

### 更新内容

- **桌面端三栏布局精修**：
  - 侧边栏、邮件列表与阅读区域支持平滑拖拽调整宽度，并支持持久化记忆恢复。
  - 侧边栏支持一键折叠与恢复，优化小尺寸窗口（1440/1280/1024px）下的响应式自适应表现。
  - 顶部工具栏适配 macOS 原生红黄绿窗口控制按钮安全边距，居中全局搜索框支持 ⌘K / Ctrl+K 快捷呼出。
- **移动端多选与安全体验升级**：
  - 移动端进入多选模式后所有邮件复选框清晰可见，退出后恢复头像，避免布局偏移（Layout Shift）。
  - 优化复选框触控热区与事件阻断，点击复选框不再误触发邮件打开。
  - 完善邮件阅读器安全风险警示条与折叠交互。
- **品牌矢量图标几何重构**：
  - 彻底重构信封与信息流双线品牌标志矢量路径，基于严格的数学贝塞尔曲线与切线连续性，消除边缘毛刺与锯齿。
  - 严格遵循克制、无渐变纯色视觉规范。
  - 针对 16/20/24/32px 系统托盘与任务栏小尺寸进行光学微调对齐，确保高 DPI 与标准分辨率下均清晰锐利。
- **Windows 系统托盘动态主题自适应**：
  - 实时监听 Windows 任务栏深浅色主题切换，浅色模式采用深色高对比度符号，深色模式采用纯白符号。
  - 完善主题切换状态机，图标真正设置成功后才更新缓存，底层异常时不污染状态并支持安全重试；不重复创建托盘实例，保留未读计数与托盘菜单。
- **工程构建与资产生成幂等性保障**：
  - 优化跨平台资产生成脚本，消除 ICNS 构建漂移，连续两轮生成达到 100% SHA256 哈希一致。
