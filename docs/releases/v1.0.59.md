## Better Email v1.0.59

本次更新引入新的跨平台应用图标，并改进邮件处理与数据可靠性。

### 更新内容

- 更新应用图标和明暗主题标识，适配 macOS、Windows 与 Android；Android 支持自适应和主题单色图标。
- 保持邮件多选布局紧凑，改进邮件操作和快捷键体验。
- 修复邮件同步、规则及备份恢复中的可靠性问题。
- 修复附件下载与缓存竞争问题，支持准确下载同名附件。
- 改进 MCP 连接兼容性：支持 2025-11-25 协议握手、更准确地处理服务地址，并在完成后释放有状态会话。
- 更换 MCP 服务地址时重新确认邮件内容授权，补充连接向导、协议和安全边界测试。

MCP 当前支持 Streamable HTTP 的 2025-03-26、2025-06-18 和 2025-11-25 协议，以及兼容的翻译、摘要和模板工具；暂不支持 stdio、旧版 HTTP+SSE 或 2026-07-28 新协议。
