# 顶部布局与 Rust 生命周期复查

基线：v1.0.55，`e3b93396f39f486c56355a8e3f94242f4d1d11a9`。

## 顶部显示根因

搜索框的辅助提示使用 `.sr-only`，但全局隐藏规则原来放在懒加载的写信样式中。首次启动、尚未打开写信窗口时，提示变成可见内容，挤占输入区域；固定五列网格还将辅助节点参与布局。将通用隐藏规则移动到启动时必加载的 global.css，并使用单行 Flex，使输入区域吸收剩余宽度，图标、范围与快捷键保持各自空间。保留 aria-describedby，不用删除无障碍说明来掩盖问题。写信组件已有的局部可见标签规则保持不变。

列表头原来被固定在 52px，邮件/会话与筛选/排序组合不换行。窄列表和文字放大时控件越过面板边界，被面板绘制隔离裁切。保留面板隔离，修改所属样式为最小高度与内容自适应，允许动作组有序换行；不隐藏排序文字或删除操作。批量工具栏采用同样的自适应高度。

## Rust 已修复的独立问题

| 路径 | 问题与改动 |
| --- | --- |
| 后台任务入队 | 单连接互斥不能阻止多个连接先查询再插入。使用 SQLite IMMEDIATE 事务串行化去重与插入，账号和任务种类分别隔离。 |
| 失败任务重试 | 旧任务失败后新任务已存在时，重试不能再造一个活跃任务；事务内复用同范围的活跃任务。 |
| 取消与进度 | 取消及取消消费使用状态条件更新，避免过期读取覆盖终态；进度限制为 0–100，不允许回退或覆盖取消提示。 |
| 任务列表 | 返回全部排队/运行项，只对终态历史保留最近 10 项，避免运行中任务被新完成记录挤出界面。这不是对执行器饥饿的修复，执行器原本使用独立 next 接口。 |
| 任务查询性能 | 为活跃任务范围及终态历史添加部分索引，回归检查实际查询计划；不把索引存在等同于真实设备性能达标。 |
| 已发送副本回调 | 迟到的失败不能把 sent 改回待留档，重复成功不能覆盖已确认的远端 UID；未发送记录不能由归档回调变成 sent。 |
| 发送演练 | RFC3339 时间用 julianday 比较真实时间而非字符串；消息移文件夹与队列更新处于同一事务；只移动本次到期项，不重新移动历史演练邮件。演练问题不等同于真实 SMTP 重复发送。 |

## 回归与执行入口

前端新增共享隐藏规则的启动依赖检查及几何断言的反例测试。浏览器回归在第一次打开写信/设置前执行，覆盖桌面 1440×900、1280×800、1024×768，列表宽度 320/388，浅色/深色，设计字体变量 100%/125%/150%，空查询与超长中英文查询，以及排序菜单的命中测试。手机搜索覆盖 390×844、393×852、430×932。字体变量放大不是 Android 系统字体或真机 WebView 的替代品。

Rust 新增独立连接并发入队、并发重试、取消终态、进度约束、历史保留、部分索引查询计划、迟到归档回调、跨时区演练与事务回滚测试。

```sh
npm ci
npm run lint
npm test
npm run build:verify
npm run test:ui
cargo test --manifest-path src-tauri/Cargo.toml --locked
cargo clippy --manifest-path src-tauri/Cargo.toml --locked --all-targets -- -D warnings
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
```

本地已运行前端回归、类型与 ESLint、构建和结构预算；Rust 格式化由校验工作流执行。实际浏览器、Rust 完整回归、Clippy、Android 构建的最终结果必须以 PR 精确 head 的 Actions 为准，不能将源码导出步骤成功当作这些检查通过。浏览器截图和日志由既有 Release 验证工作流保存。

## 边界与后续验收

保留现有 UI 设计和安全过滤，不增加新的 final/polish 覆盖层，不修改版本号、发布规则或主分支保护。真实服务商、Android 真机键盘/字体缩放、Windows 高 DPI 与 macOS WebView 仍需验证。

本次不是整个 Rust 模块无缺陷的证明：多进程启动恢复策略、任务 attempt 标识、远端留档租约超时后的请求去重，以及长期运行的数据库/内存性能仍需独立测试。数据库只增加索引；发送中/结果未确认等既有保护不回退。操作只进入新 PR，本轮不合并、不发布。
