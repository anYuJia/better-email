# Better Email v1.0.56

发布日期：2026-09-07

## 修复

- 修复首次启动时顶部搜索辅助说明错误显示为第二行、挤压搜索输入框的问题。
- 修复窄列表、字体放大和部分窗口尺寸下筛选/排序控件被裁切或显示不完整的问题。
- 修复后台任务跨 SQLite 连接并发入队可能重复创建活跃任务的问题。
- 修复失败任务重试、取消与迟到进度更新可能覆盖新状态的问题。
- 修复已发送副本留档回调的迟到结果可能降级已确认发送状态或覆盖远端 UID 的问题。
- 修复发送演练中 RFC3339 时间按字符串比较、以及消息移动与队列状态不同步的问题。

## 质量

- 增加顶部搜索与列表工具栏的真实 Chromium 几何、命中和响应式回归。
- 增加后台任务并发、重试、取消、索引查询计划、留档状态和演练事务回滚测试。
- 发布前继续执行 TypeScript/ESLint、前端测试、UI smoke、Rust tests、Clippy、rustfmt、依赖审计和版本一致性检查。

## 发布说明

本版本基于已通过 PR #23 精确 head 验证的修复，并将仓库发布提交约定与 `AGENTS.md` 的 `feat:中文` 规范统一。正式安装包和更新载荷仅在 GitHub Release 工作流全部成功后发布。
